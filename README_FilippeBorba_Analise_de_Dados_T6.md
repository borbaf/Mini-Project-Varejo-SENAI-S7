## Como executar

**No VsCode (Windows):**
1. Abra a pasta do projeto no VsCode.
2. Crie o ambiente virtual: `python -m venv venv2`
3. Ative: `venv2\Scripts\activate`
4. Instale as dependências: `pip install -r requirements.txt`
5. Execute: `python Mini-Project-Varejo-SENAI-S7.py`

**No Google Colab:**
1. Envie os arquivos do repositório para o Colab.
2. Instale as dependências: `!pip install -r requirements.txt`
3. Rode o script.
